# Gestor Integral Farmacias 💊

**Version:** 1.0.0  
Gestor Integral Farmacias is a lightweight single-file web tool for technical audits, hardware/software management, and commercial visits in pharmacies.

---

## Features

* **Single-File Architecture:** Self-contained HTML with interface logic and local styles.
* **Pharmacy Management:** Client data, network structures, and peripherals tracking.
* **Hardware Auditing:** Scalable workstation setup for standalone or server-client configs.
* **Visit Tracking:** Chronological logging of visits with summary notes.
* **Storage & Persistence:** Optional Google Auth cloud sync via Firebase, plus local JSON import/export and PDF printing.

---

## Languages

* **Interface:** Spanish (`es`)
* **Code Comments:** English (`en`)

---

## Usage

* **Online:** Access the tool directly via [Access Tool Online](https://zuhaitz-arbola.github.io/GestorIntegralFarmacias/) to use cloud sync features.
* **Local:** Run `index.html` locally in any modern web browser. *Note: When running locally, data can only be saved and loaded locally (via JSON files).*
